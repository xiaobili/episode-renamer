## STRM 按用户反馈修订（同日）

- **远端自定义目录搬进工作区左栏**：删掉 `settingsSchema`/`settings` 里的
  `strm.remoteRoot`，改由 `workspace.strmRemoteRoot` 持有，持久化到独立键
  `episode-renamer:strm-root`（不共用 settings：设置页草稿保存会把它盖回旧值）。
  左栏输入框 + 「浏览」复用 OpenList 浏览对话框，新增 `browse.target='scan'|'strm'`，
  选 strm 目录不会改掉扫描路径；strm 目标允许选挂载根。
- **指定根目录先建剧集名目录**：`core/strm.py` 新增 `show_dir_of`（parsed.show_name →
  落点目录名 → 扫描根名，经 `safe_filename`，拒 `.`/`..`）与 `rooted_rel_dir`
  （首段与剧名同形时去重）。落点 = `{根}/{剧名}/{相对扫描根}/{文件名}.strm`，修掉
  「扫描根就是剧目录时全平铺进根目录」的缺陷。
- **URL 不转义**：`build_strm_url` 去掉逐段 `quote`，原样写 `{base}/d/{远端路径}`。
  代价：文件名带 `#`/`?` 时播放器当语法，链接必 404（已写进 spec §10）。
- 判据：后端 340 passed（strm 相关 57 条）；前端 11 脚本全绿（工作区 87 项）；
  `npm run build` 正常成功（这次没有被 fs shim 打断）。
