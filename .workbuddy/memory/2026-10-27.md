## 剧集文件夹改名 `剧名 (年份) [tmdbid-x]`（同日）

- 设计/规格：`docs/superpowers/specs/2026-10-27-show-folder-rename-design.md`。
- 用户选型：**带空格**（Emby 官方写法）+ 剧名取 **TMDB 本地化标题**；年份缺失时省略括号段。
- 新增 `models/show_folder.py`（`ShowFolderPlan`）与 `core/show_folder.py`：
  `build_show_folder_name` / `plan_show_folders` / `apply_local_show_folders` /
  `apply_openlist_show_folders`。剧集根复用 `nfo_writer.show_root_of`（新增的公开别名，
  内部仍是 `_show_root`）—— 季目录上溯只允许有一份实现。
- **顺序是设计核心**：execute → finalize → **folders**。先改目录会让
  `write_nfo_files` 的 `mkdir(parents=True)` 在旧名下重建目录，产出「只有 tvshow.nfo
  的空文件夹」。前端 `executeAction` 里三个块的位置就是这个顺序，已被
  `check-execute-behaviour.mjs` 场景 F 用调用下标钉住（变异测试：交换两块 → 恰好 1 红）。
- 新接口 `POST /api/rename/folders`（`RenameFoldersRequest`）：不读 `conflict_strategy`
  （目录不覆盖、不自动编号），OpenList 侧先列父目录判撞名再 `rename`（远端没有 exists）。
- 拒绝矩阵：未匹配 TMDB / 同目录混放 / 目录嵌在别的剧里（只拒祖先）/ 已是目标名（幂等）/
  **剧集目录直接挂在根下**（`/media` 这种挂载点，新增 `ROOT_TOO_SHALLOW_REASON`）。
- 前端：左栏「同时重命名剧集文件夹」勾选框（默认关）；FileTable 的 `NFO / STRM` 列
  改名为 `NFO / STRM / 目录` 并显示目标目录末段；ResultDialog 新增「剧集文件夹」块
  （单位是**部剧**不是文件）。执行后 `_remapScanPath` 把 `path` 前缀改写到新目录，
  否则「扫的就是剧目录」那种最常见的用法会导致重扫必失败。
- 判据：后端 **376 passed**（新增 37 条：命名/上溯/混放/幂等/本地真改名/OpenList 调用/
  路由/端到端「NFO 随目录搬走」）；前端 11 脚本全绿（执行行为 36 项、载荷新增 13 项）。
- **构建坑（复现）**：`npm run build` 在 `prepareOutDir` 阶段拷贝 `public/favicon.svg`
  时被沙箱 fs shim 拦（`wrappedCopyFileSync`），而且**已经清空了 dist** → `app.main`
  导入失败、整套 pytest 收集报错。处置：`git checkout -- frontend/dist` 先恢复，
  再用临时配置 `publicDir: false` 构建，favicon 事后手工写回 `dist/favicon.svg`，
  临时配置删除。下次构建前先确认 dist 已在 git 里，别让失败把产物清空。
